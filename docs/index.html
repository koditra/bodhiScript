About

bodhiScript is a small programming language inspired by Hindi, Sanskrit, and Java.

Examples

hello world
likha("Hello, World!");
variables
maan naam = "Aashvik";
rakho age = 14;

likha(naam);
likha(age);
conditions
maan age = 14;

yadi age >= 13 {
    likha("Teenager");
} anyatha {
    likha("Not a teenager");
}
functions
karya greet() {
    likha("Namaste!");
}

greet();

Install

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/koditra/bodhiScript/main/install.sh | bash

Windows PowerShell

iwr https://raw.githubusercontent.com/koditra/bodhiScript/main/install.ps1 -UseBasicParsing | iex

Then run a file:

bodhi hello.bodhi
